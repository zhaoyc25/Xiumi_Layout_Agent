# 本地文章导入微信公众号

把本地排版完成的 HTML 填入已经打开的微信公众号图文编辑页。扩展不会保存、群发或发布文章。

## 安装

1. 在 Edge 打开 `edge://extensions/`，或在 Chrome 打开 `chrome://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录 `wechat_import_extension/`。

## 使用

1. 登录微信公众平台，打开“新建图文”编辑页面并保持该标签页开启。
2. 点击扩展图标，选择目标微信编辑页。
3. 选择 `.html`、`.htm` 或 `.json` 文件。
4. 检查或填写标题、摘要、作者和原文链接。
5. 点击“导入到微信编辑器”。
6. 返回微信页面，人工设置封面，检查图片和格式，保存草稿并手机预览。

完整 HTML 文件会优先提取 `article`、`main` 或 `.rich_media_content` 内部内容；没有这些容器时使用 `body` 内容。标题取自 `<title>`，摘要取自 `<meta name="description">`。

JSON 格式如下：

```json
{
  "title": "文章标题",
  "desc": "文章摘要",
  "html": "<section>排版后的正文</section>",
  "wxAuthor": "作者（可选）",
  "wxLink": "https://原文链接（可选）"
}
```

正文图片必须使用 `https://`、`http://` 或 `data:` 地址。扩展会拒绝 `file://` 和相对路径图片，且不会把本地图片上传到微信。正式使用推荐先把图片上传到可信图床或微信素材库。

扩展依赖微信编辑器当前页面结构。微信后台改版后，如提示找不到编辑器，需要相应更新页面选择器。
